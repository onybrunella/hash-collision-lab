# hash-collision-lab

**Collision Resistance in Cryptographic Hash Functions: Theory vs. Practice**

Group project for Network and Information Systems Security (SRSI), ISCTE-IUL, 2026/2027.

## Goal
We study whether the collision resistance of a hash function depends on its output size or on its internal design, by comparing MD5, SHA-1, SHA-256 and SHA-3.

## Repository structure
- `report/` : the written report (Part 1)
- `code/` : Python source code for the experiments (Part 2)
- `results/` : raw data and graphs
- `docs/` : literature review material and notes
